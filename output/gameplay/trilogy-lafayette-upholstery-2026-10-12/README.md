# 1-06 Lafayette 皮椅：局部制作与实际验证

2026-10-12，基于 `bc28dfa`。本轮改善两把会客厅皮椅的软垫厚度、菱格凹陷和木雕扶手，并补同步的共享轮廓。药丸剧情、座位、桌面、手部目标和房间尺度不变。**1-06、P0 和三部曲都未高质量完成。**

## 原片依据与本轮范围

原生浏览器查看 [Movieclips 的红蓝药丸片段](https://www.youtube.com/watch?v=zE7PKRjrid4)，暂停核对约 1:48 与 1:58：红褐色皮革、深菱格、圆厚椅背和深色雕刻扶手。原片截图只留本地 `reference-108.png` / `reference-118.png`。`reference-wide.png` 实际是片尾画面，不能作为房间布局依据。

这些镜头不足以确认整间会客厅、壁炉和窗户的准确尺度，本轮没有据此重构房间。模型仍是程序制作的近似资产，雕刻端头也只是圆形眉眼/口鼻轮廓，没有声称复制原片道具。

- 椅背由连续闭合网格构成，前面有连续菱格软垫、折缝和实际凹陷的纽扣，后面加厚。
- 扶手顶部和端头使用深色木料；保留原扶手高度，避免改变已有手掌目标。
- 椅子仍合并为四个材质批次，细小圆饰降低分段数；复用已有皮革贴图，没有新增依赖或位图。
- 最初菱格过尖，原生检查后调圆。`after-neo-interim.png` 与 `performance-interim.json` 属于被修正的版本。
- 新椅背超过旧轮廓，先复现失败，再增加共享 `backOffset`；Lafayette 的左右转向轮廓和 Construct 的共享家具轮廓都覆盖实际边界。构造体这里只验证定义/实际模型接触，没有重新验证其完整自由行走机制。

模型原点下的实际边界为 x ±1.22525、z −1.26750 到 +1.00994；共享轮廓为宽 2.5、深 2.35、向后偏移 .13。Lafayette 按两把椅子的实际朝向旋转轮廓。座位/药丸接触位置未移动。

## 真实存档与实机流程

隔离副本来源为上一轮 `answer-cold-fixed-state`，从 talking 第 1 拍、1.282 秒 / tick 4670 开始，复制全部世界和 7 份记忆。本轮没有修改人物或剧情 JSON 来摆拍。来源的早期历史曾补入较晚的 7 份记忆，不能把其祖先称为同一时刻的完整历史快照；本轮的成对重启使用当时完整副本。

原生界面依次追问矩阵、追问认知边界、听两种选择、选择红药、取药/喝水/起身，然后实际 WASD 跟随 Morpheus 穿过后门，到 `m1_mirror` 第 0 步 / tick 5510。没有继续坐椅、接线或银色覆盖。检查包含暂停，不是无中断电影流程。
