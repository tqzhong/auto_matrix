# 排水道出口到电视维修店：本轮验收

日期：2026-10-01

## 范围

本轮只处理 `m1_tv_exit` 的空间连续性：四人离开排水道后，从白昼街角的出口井出发，由玩家控制 Neo 穿过路面和人行道，进入电视维修店，绕过柜台并抵达后墙硬线。既有的 Cypher 飞船袭击、Tank 反击、Apoc / Switch 死亡及 Trinity、Neo 依次接出继续沿用同一剧情状态。

## 已实现

- 将场景入口从店内电话附近移到街边出口井，任务由三个操作步骤扩为四个。
- 增加道路、人行道、路沿、车道线、出口井与移开的井盖、街灯、报刊亭、停靠车辆、对街建筑、店铺立面、橱窗和中央敞开门。
- Neo 必须亲自走进店门并沿柜台右侧通道抵达电话；实体橱窗阻挡通行，门洞和柜台缺口保持开放。
- Trinity、Apoc、Switch 使用三条独立路线跟随 Neo，路线按玩家实际进度推进，不在过场开始时传送到店内。
- 旧版已经位于店内的存档保留 Neo 的位置，并把缺失的同伴街面进度补到店内终点，避免读档倒退。

## 验证

- 先增加失败回归，旧实现因 `m1_tv_exit` 仍只有三个步骤而失败；实现后通过。
- 专项回归：`basement-escape`、`basement-render`、`basement-ui`、`cypher-crosscut`、`film-story`，共 120 项通过。
- 全量回归：919 / 919 通过，无失败、取消或跳过。
- `npm run typecheck` 通过。
- `npm run build` 通过；客户端仍有既有的 500 kB 以上 chunk 提示。
- Codex 侧边栏使用隔离存档检查了白昼街角入口、店门内部可见性、三名同伴起始位置和镜头环顾；页面日志无 warning / error。该检查没有把整条路线录成视频，也不等于连续人工长玩。

## 未完成

- 当前街景可以辨认和行走，但建筑立面、店招、橱窗陈列、行人和车流密度仍是样板级，尚未达到电影成片质感。
- 出井、跨路沿和进门仍使用通用步行动作，缺专用身体受力、脚部接触、服装和面部表演。
- 本轮没有新增正式环境声、对白、录像或独立帧率样本；此前营救决定机位的 16.77 fps 性能问题仍未解决。
- 本轮只补齐一个连续片段，不改变 1-11 和三部曲整体的未完成状态。
