# 1-06 Lafayette 房间：结构制作与实际验证

2026-10-12，基于 `cfd8230`。本轮制作会面房间的墙板、窗户、帘布、地板与壁炉，保留既有人物、座位、交接目标和酒店路线。**1-06、P0 与三部曲仍未高质量完成。**

## 成片依据与范围

原生浏览器查看 [Warner Bros. Entertainment 官方红蓝药丸片段](https://www.youtube.com/watch?v=ky7ksownEEE)，核对约 0:05、2:00 和 2:10 的人物近景与背景。另查看 FlashbackFM 的 [All I'm offering is the truth · Open Matte](https://www.youtube.com/watch?v=6rrPP-QOF3k)：0:00 的入门、0:05 窗前、0:20 握手、0:25 椅旁、0:30 壁炉。这是原片的公开片段，但第二个发布者不是 Warner Bros. 官方。没有观看或下载完整三部影片。

宽镜头支持高墙板与厚门套、低窗台、褐色垂帘、拼花地板和带弧形炉口的雕花壁炉。它们不能提供准确的完整平面尺寸。本轮房间仍沿用 42×50 的游戏布局，顶高由 14 降至 10.8；不是原片房间的测绘复制。

- 墙面由有厚度的漆面线脚、凹入的花纹面板及下部护墙组成，保留后门和酒店入口。追踪室隔墙的共享碰撞厚度改为 1.25，覆盖两侧凸出的线脚。
- 窗台由 3.2 降到 .85，玻璃、窗框、垂帘随房间高度调整；减弱回光与轮廓光，复用已有材质。
- 地板改成实体人字拼花，板面在既有行走地面高度上，缩小会客厅地毯，露出更多木地板。
- 壁炉重做真实弧形孔洞、炉内暗面、分层台沿、较小的浮雕和中心椭圆饰。宽/深/高改为 6.8 / 1.15 / 4.55，共享碰撞同步；不是贴一张拱门图片。
- 最初线脚大量使用细密圆角，帧内提交三角形增加约 104 万；实际几何预算检查复现失败（线脚 178,380 三角形）。随后改为平直实面线脚，保留厚度、凹槽与碰撞，不修改其他场景的圆角函数。

没有新增依赖、模型或位图。现有墙纸/地毯仍是此前生成的材质演绎，木料、灰泥和石材也不是原布景扫描。

## 性能和录像

同一暂停 Neo 坐姿、1280×720、像素比 1.5、关闭录制，预热 3 秒后采样 15 秒。改前 `performance-before.json` 为 36.786 FPS / p95 28.6 ms / 446 次绘制。圆角优化前为 20.971 FPS / p95 53.4 ms / 476 次绘制，帧内提交 4,177,196 三角形；最终 `performance-final.json` 为 **21.714 FPS / p95 50.8 ms / 476 次绘制 / 3,324,716 三角形**，减少 852,480 三角形，但样本仍低于改前帧率。**性能未通过，不能称为稳定提升。** 最后采样已关闭临时电影参考标签且编译/回归全部结束，机器状态和样本时间仍不同；这是单次实测，不是严格受控的性能因果实验。

`performance-during-build.json` 同时运行编译，不能用于比较；`performance-ratio-1.json` 为像素比 1，也不能与改前 1.5 混比。代码没有自动画质降级：渲染器在初始化时读取浏览器像素密度，窄窗口测试影响了该值；重置尺寸设置后已经检查 1920×1080 实际画布对应 1280×720 页面。

- [会面、红药、进入追踪椅，约 6 分 27 秒](../neo-longplay-2026-09-20/neo-2026-10-11T18-40-46-681Z.webm)：73,001,580 字节，有检查停顿及回归 CPU 并发；音频包跨度 386.758 秒，视频包跨度 386.383 秒，4747 个视频包。源帧计数和录制设置不能当作稳定实际帧率。
- [冷读后触镜至培养舱，约 1 分 30 秒](../neo-longplay-2026-09-20/neo-2026-10-11T18-49-51-490Z.webm)：15,254,069 字节，音频/视频包跨度 89.639 / 89.560 秒，1430 个视频包。

两段均为实际 1280×720 VP9 / Opus 录像，只有本地文件。元数据与 ffprobe 包检查见 `video-probe.json` / `mirror-video-probe.json`，它们均早于最后线脚简化。

另有[最终版冷读触镜至培养舱，约 1 分 29 秒](../neo-longplay-2026-09-20/neo-2026-10-11T19-18-12-321Z.webm)：12,796,115 字节，1475 个视频包，视频跨度 88.668 秒、音频跨度 88.737 秒，仍包含检查停顿。`final-video-probe.json` 保存实际结果。录制中的 FPS 不能替代上述无录制、固定视角性能样本。
