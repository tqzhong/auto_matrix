# 道场足底计算与帧率（2026-10-24）

本目录最初用于调查道场室内还原；实际提交范围为测量发现的足底CPU瓶颈。封闭双层道场尚未制作，不能凭目录名称计入场景完成。

## 修正范围

基线 `489d0f3a057f37eabbbd23747ee4fe80b4b14711`。仅修改 `HeroModel.ts`：原实现对Neo/Morpheus的8988/8936个脚底顶点逐一调用 `localToWorld` 和 `worldToLocal`，即使祖先不变也每帧重算18034/17930次祖先矩阵。改为刷新蒙皮绑定变换后，每角色共用一次网格到身体的变换，再遍历全部顶点求接地点。

没有抽稀脚底、减少模型、改变纹理/阴影或引入依赖。共用一个Matrix4，无新增逐帧分配。还修正了移动到已平移、旋转、缩放的父对象后，旧绑定逆矩阵导致冷放置接地错误的问题。

## 实测

Apple M3、24GB；同一暂停道场、同镜头、1066×600 CSS视口、像素比0.75，推算绘制缓冲约799×450。每次预热3秒、采样15秒，无录像、GPU查询或并行构建/测试。不是1080p测试，也不是连续战斗测试。

| 样本 | FPS | P95帧间隔 |
| --- | ---: | ---: |
| 原版1 | 21.96 | 51.6ms |
| 原版2 | 21.59 | 53.3ms |
| 优化1 | 44.78 | 27.2ms |
| 优化2 | 53.18 | 23.3ms |

两组主对照每帧均为1602次绘制、1646081个三角形；回切原代码的少量帧相差2次绘制/256三角形，不宣称五组完全相同或逐像素相同。没有独立GPU耗时，渲染提交CPU计时不能冒充GPU时间。P95仍超过16.7ms，稳定60帧没有达标。
