## 最新：收手与袖口通行

- 先复现了一个不可能满足的约束：袖口沿固定世界方向下降，手掌却沿另一条路径退出。1.3 秒实际手部截面越出原袖口约 **3.66cm**。仅改为沿手腕轴向滑动仍失败，张开的拇指无法通过开口。
- 增加收拢拇指、轻收食指/小指、退出后恢复的动作。第一次完全收拢导致掌根约 590 组自交，已舍弃；当前幅度在 18 个实际双手姿态中没有检出自交，拇指中节/末节最大弯角约 36.31° / 22.96°。原皮肤、关节长度和蒙皮权重不变。
- `WithdrawalCuffs.mts` 让原有完整袖口先绕过拇指，再转过指根、滑过指尖，手离开后继续下移。0.8–3.2 秒按 120Hz 取 289 个时刻、578 次双袖口检查，其中 140 次切到实际手部截面；扣除袖口非平面偏差后，最小通行余量约 **1.21mm**。袖口尺寸未放大；单步最大位移约 .02443 模型单位，冷载坐标差约 `2.4e-14`。
- 60Hz 初版通过后，120Hz 加密曾发现约 0.1mm 的余量不足，失败日志保留；修正后的完整专项在隔离发布目录 **8/8 通过**。包括原身体五项、实际手指、袖口通行，以及完整袖口尺寸/连续性/冷载恢复三项。六个直接运行输入逐字节与已发布源码/GLB 核对。

这些是游戏动作制作选择，原片遮挡处并未提供完整手指或袖口运动证据。[手部近景](thumb-after-thumb.png)与[袖口截面](cuff-section-final.png)均为离线诊断图。

## 首轮身体路径的实际修正

- 新复现捕获 2.8–3.2 秒上臂袖片穿入躯干：3.2 秒为 382 组新增交叉。单独延后起身只能减到 52 组，不能解决问题。将退出位置从背后中线移至身侧后，这些新增交叉消失；随后提前恢复原起身时机，消除恢复阶段因肘部过度弯曲引起的 25–50 组袖片折叠。
- 补充 3.2–8 秒手臂恢复路径。左手先绕过髋部回到身侧，右手保留持衣所需位置后再回到原姿态；原结束时约 1.425 模型单位的表面跳动不再出现。**这还不是抓衣成品：手指与真实衣物的夹持、松开和后续衣物落地尚未完成。**
- 对完整外套检查发现，原手部直线路径在 0.3 / 0.4 秒分别与下摆产生 34 / 336 组交叉；并非袖口绑定错误。增加绕髋的手部弧线后，准备阶段 49 个 60Hz 样本对完整 25,796 面外套、翻领、两片尾摆及全部 13 个可见内层未检出交叉。
- 身体退袖 12 个、恢复 13 个关键姿态均无新增衬衣自交或手部/衬衣交叉。既有门襟的 23 组细小自交仍存在，没有删除衣面或放宽接触容差来隐藏它们。
- 八秒共 481 个连续性样本，最大单帧皮肤表面位移约 .05022 模型单位；足底位置最大偏差约 `7.47e-16`，手腕目标最大误差约 `1.20e-15`。这些是有限姿态与数值检查，不是任意动作或原生性能验收。

冷模型对照初次失败：带平移、旋转与 .4 倍缩放的模型在未播放动作的 t=0 就已有约 `1.49e-6` 的表面坐标差，来自 float32 世界蒙皮换算；各时刻误差相同。独立控制保留在 `cold-transform-control.json`。最终先核对求解后骨骼，再将两套真实表面放入同一坐标系，最大骨骼差约 `1.24e-14`、表面差约 `2.29e-14`。原全文件结果 4 通过 / 1 失败保留；修正后的冷读检查单独 1/1 通过，没有改变几何接触判定。随后在不含脱衣运行时实验的发布目录复测完整文件，**5/5 通过**；HeroModel、衣物/尾摆、动作、IK 源码与 GLB 六个直接输入均逐字节核对为已发布版本。

## 完整外套仍未通过

输入始终保留完整显示网格、13 个实际身体/内衣层及真实袖口环；未用简化身体替代最终接触检查。以下交叉数量不是穿入深度。

| 对照 | 1.3 秒自身 / 人体交叉 | 1.6 秒自身 / 人体交叉 | 3.2 秒自身 / 人体交叉 |

| 完整外套自 0 秒直接模拟，较早延迟起身路径 | 1,163 / 940 | 未取此点 | 6,602 / 0 |

制作尺度为 100；上表间距 .001 / .05 对应原米制 .01 / .5mm，人体与衣物的有效间距合计约 1mm。更细子步减少人体交叉却加剧袖片折叠，不能宣布“提高精度已解决”。分区检查显示最终 446 组中，袖/袖 172、躯干/躯干 160、领/领 29；不是仅有翻领或尾摆接缝。详见 `self-regions.json`。
