# 墨菲斯旧楼奔跑：上衣与薄包边修正（2026-10-22）

已更新固定本机试玩 <http://localhost:5173/>。打开“检视三维人物 → 墨菲斯”，动作选择“旧楼 · 行走”或“旧楼 · 奔跑”。这是实际游戏模型及同一套动作代码；人物检视画面不等同于整段剧情游玩或电影质量验收。

## 根因与改动

制作腰缝时发现两个更早存在的问题：原上衣在启动奔跑0.45秒处，与真实长裤有23处三角面交叉；0.1833秒处薄下缘有8次自交计数（含双向计数）。旧检查覆盖90个姿态，每12帧取样，没有覆盖这些早期时刻。`running-contact-red.log` 和 `baseline-early-fold.json` 保留原实现失败，原有两项上衣回归仍2/2通过，不能用间隔采样通过代替连续帧检查。

- 原抬腿形变在网格空间制作，会随髋骨旋转，不能保持身体外侧的余量。新增 `AmbushHipClearance`，使用每个点当前的真实骨骼混合矩阵，把修正保持在骨盆空间，再转换回网格。使用原抬腿场的1.5倍余量，仅修改上衣局部755点。
- 薄下缘帽面与向内包边共31个点跟随邻接外衣面及法线，保留向内厚度，避免微小折边翻到外衣面外侧。局部837点按实际组合形变重建法线；保留有意的法线分界和重合的UV接缝。原634组重合顶点在120帧中最大分离为0。
- 深蹲时平滑退出这项抬腿修正，离开旧楼服装时恢复原坐标和法线。暂停保持几何、不重复上传；已有暂停、冷重建和离场回归覆盖此行为。
- 新增旧楼行走/奔跑预览，只对墨菲斯开放；切回Neo会恢复待机并禁用这些选项。原来的蹲起和蹲行保留。

原上衣/尾摆的完整拓扑、UV、全部5,120个尾摆三角面、碰撞容差和内层身体均保留。没有新增依赖或运行素材，没有采用接缝实验、修改存档格式或接入离线脱衣缓存。
