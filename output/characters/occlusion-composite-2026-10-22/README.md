# 接触阴影合成与帧率核对 · 2026-10-22

基线 `0697449211cf4ac3eaba73b42634728ae5e2838a`。本轮省掉正常接触阴影合成的一次整屏颜色拷贝，没有证据证明稳定提帧，未达到60fps。三部曲电影质量仍为0/42组，人物腕口、皮肤、手部与材质问题仍存在。

## 实现

[WorldOcclusionPass](../../../packages/client/src/engine/PostProcessing.ts) 保留现有法线、8个AO采样、降噪、分辨率、半径与强度。默认离屏输出时，将独立的降噪AO纹理直接乘入已有场景颜色缓冲，并告诉 EffectComposer 不交换缓冲；不采样正在写入的颜色纹理。调试输出、直接上屏、模板遮罩和显式开发对照继续使用原拷贝路径，异常后清除临时抑制状态。

依据为当前安装的 Three.js `GTAOPass.js`、`EffectComposer.js`、`GTAOShader.js` 和 `CopyShader.js`：默认输出先拷贝场景颜色，再以目标颜色乘法混合AO；Composer在pass返回后检查 `needsSwap`。没有修改第三方依赖。

开发性能面板增加原路径对照项和默认的CPU/FPS采样模式，该模式不在测量帧中插入GPU查询，避免上一轮发现的计时提交干扰。开发面板不进入正式构建。
