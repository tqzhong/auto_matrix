# 人物动画耗时定位与道场足底坐标复用（2026-10-24）

用户正在追问低帧率与 60 FPS 的硬件要求。本单元先测量真实浏览器的人物分层耗时，再只优化已确认的道场足底坐标变换。没有新增资产、依赖或付费服务；Render 不接回，固定试玩入口 http://localhost:5173/。

## 实际修改

- `PerformancePanel.ts` 的自愿开启开发模式采样记录每个角色的整体、英雄骨骼、手部计算。三个层次互相包含，不可相加；采样结束恢复所有方法。生产构建不启用这个面板。
- `HeroModel.ts` 把绑定矩阵并入每帧的骨骼矩阵，把逆绑定与身体坐标变换合并，最终只求脚底高度。仍遍历 Neo/Morpheus 全部 8,988/8,936 个脚部顶点，保持原权重、模型、手部、衣物、阴影和画质。
- 新增两项实际人物预算回归。Neo 原版每帧调用 37,438 次顶点矩阵变换，其中足底有效权重只需 10,442 次；旧流程每顶点多做三次公共坐标变换。

- 修改前相关 13/13；新增预算测试原版 2 失败、原有 2 通过；修改后相关 15/15。包含完整足部接地、旋转/非均匀缩放、走跑/连击/闪避、拳面与道服接触、冷加载和动作边界，未放宽原容差。
- 72 组旧/新姿态的可见网格位置、法线、权重与骨骼索引哈希全部相同；728,640 个网格/绑定/骨骼矩阵分量最大差异 8.882e-16。原始矩阵记录以 `before-poses.json.gz`、`after-poses.json.gz` 保留。

- 正式客户端类型检查/构建通过，保留既有大包警告。1,215 个代码/配置/测试/资产输入冻结；共享与 280 个服务端产物和正式版本相同。
