# 墨菲斯旧楼退袖：当前服装与物理制作对照

2026-10-19。离线制作记录，不是游戏实录或完整脱衣验收。本轮没有修改运行时代码、角色 GLB、贴图或存档；普通剧情入口仍未启用未完成的八秒脱衣。线上游戏仍为 `113ffe7`，不是这些实验。

## 实际输入与基线

- 使用当前 `HeroModels` 生成的墨菲斯外套、翻领和两片完整尾摆：25,796 个显示三角面，按位置合并为 13,386 个物理点；全部 13 个可见人体与内层网格作为碰撞输入。没有删除衣片来消除交叉。
- 重新检查旧 V33 原型：它会恢复旧尾摆形状，起始即有 69 组自身、374 组内层交叉；2.1 秒有 296 组手部交叉，6.6 秒有沉地。不能把它接到已经修好的当前衣服上。
- 新的 `WithdrawalBody.mts` 只作为制作输入。修正超出臂长的手腕路径，增加小幅身体下沉并保持足底；97 个有限输入采样中最大 IK 目标误差约 `9.04e-16` 模型单位。但 3.2 秒实际衬衣仍有 419 组自身交叉，身体演出尚未通过。
- 当前游戏相关基线为 13 项中 9 项通过、4 项失败：服务器脱衣时钟 7/7、当前穿着外套 2/2；客户端世界外套、冷读、跨世界显示和资源恢复 0/4。失败测试未删除或跳过。完整八秒动作尚未接入渲染器。

## 静止漂移的可复现原因

控制使用同一完整服装、静止人体/袖口、零场景重力、30 fps、20 子步，持续一秒。实际袖口目标曲面在四个采样时刻完全不动，排除了暗中移动约束。表中数值为一秒末尾最大漂移，单位为米。

| 控制 | 漂移 | 结论 |
| --- | ---: | --- |
| 原参数，人体与自碰撞都开 | 0.119608 | 静止控制失败 |
| 关闭两类碰撞，原弯曲阻尼 0.5 | 0.0436262 | 不能只归因于碰撞 |
| 再把弯曲刚度及其最大值都设为零 | 0.0387032 | 刚度最大值不是原因 |
| 保留弯曲刚度，仅将弯曲阻尼设为零 | 0.000000460 | 默认阻尼引起的稳定性问题被隔离 |
| 无碰撞，保留较小弯曲阻尼 0.003 | 0.000000484 | 不必完全取消阻尼即可稳定 |
| 原尺度恢复两类碰撞，阻尼 0.003 | 0.138478 | 初始碰撞间距仍不合适，不能作为修复完成 |
| 放大 100 倍制作、换算回原米制，开启两类碰撞、阻尼 0.003 | 0.000000432 | 一秒静止控制通过；起止两帧实际完整衣物自身及全部内层交叉均为零 |

原始每点质量约 0.000224 kg。核对 Blender 4.5.3 的实际角弹簧实现后，对照只改变弯曲阻尼即可消除无碰撞漂移；这项结论限定于本输入与设置，不意味着其他布料都应使用 0.003。[角弹簧力实现](https://raw.githubusercontent.com/blender/blender/v4.5.3/source/blender/simulation/intern/implicit_blender.cc)

第二个原因是尺度和最小碰撞距离：实际衣物顶点至衬衣表面的最近采样约 0.286 mm，衣物顶点至不包含该点的衣物三角面最近采样约 0.0225 mm；后者也包含相邻区域，不是全网格连续最小距离证明。Blender 将小于 0.001 的碰撞距离静默截到 0.001。直接填更小数值的对照产生了逐帧相同的结果，读取实际设置确认参数没有生效。放大制作尺度后，重力和拉伸/压缩/剪切刚度作对应单位处理，输出重新换算为原坐标；不能只放大人物而沿用原动作/重力。[碰撞参数范围](https://raw.githubusercontent.com/blender/blender/v4.5.3/source/blender/makesrna/intern/rna_cloth.cc)

静止通过不等于自然皮革或动态碰撞通过。起止两帧接触检查不是一秒内所有连续时刻无交叉的证明。原先简化网格在初始就有 925 组人体交叉，外扩简化网格又出现 312 组自身、263 组人体交叉，两者均未采用。

## 尺度转换检查与动态结果

97 帧实际人体输入另行检查了放大、关键帧求值与缩回米制的全过程：最大差异 `2.384185791015625e-7` 米，最大归一化浮点误差 1.5 ULP。首次检查沿用未缩放的 1 ULP 门槛而停止；现在在原米制比较，并为两次额外 float32 换算保留 2 ULP 容差，未放宽几何接触判定。

原始失败文件、前 14 个完整帧与第 15 帧中断保留在 `scaled-physics/`；重新检查的动态输出为 `scaled-physics-checked/`。97 帧烘焙完成，但动态接触未通过：

| 时刻（秒） | 衣物自身交叉 | 衣物与全部实际内层交叉 |
| ---: | ---: | ---: |
| 0 | 0 | 0 |
| 0.5 | 318 | 2,573 |
| 0.8 | 423 | 2,834 |
| 1.3 | 517 | 3,189 |
| 1.8 | 2,852 | 2,123 |
| 2.2 | 4,096 | 1,428 |
| 2.6 | 4,666 | 1,129 |
| 3.2 | 4,476 | 839 |

因此，缩放与阻尼修正只解决静止控制，不能作为退袖成品。缩小有效碰撞余量后，动态的袖道和衣物褶皱仍相互穿过；下一步须修正实际袖口/身体路径和可满足接触余量的模拟拓扑，再接抓领与落地。直接简化或统一法线外扩均已失败，不应再次直接作为有效起始网格使用。

已查看实际缓存的[0.8秒背面](scaled-physics-checked-25-rear.png)与[3.2秒正面](scaled-physics-checked-97-front.png)离线诊断图：前者可见袖部穿插，后者衣物仍严重折叠、身体姿态也未达到自然演出要求。图像带有离线/非游戏截图标记，使用诊断材质，仅作为拒收证据。

## 文件与复现

- [完整静止控制与实际参数](control-results.json)、[输入与脚本哈希](source-digests.json)。原始大体积制作输入、逐帧坐标、`.blend`、诊断图与日志保留在本目录，仅用于本地制作，没有作为游戏素材发布。
- `export-current-input.mts` 从实际模型生成 `current-input/`；`bake-rest-control.py` 保留各个单因素控制；`bake-rest-scale.py` 是开启两类碰撞的缩放静止控制；`bake-scaled-withdrawal.py` 使用同一完整网格与全部人体采样进行移动烘焙。
- `audit-withdrawal.mts --physics --folder=rest-scale-100 --frames=1,31` 检查实际输出的交叉；判定仍使用原模型单位和原截线容差。动态烘焙须另查所有关键接触阶段，不能用静止结果替代。
- `review-cache.mts` 与 `render-cache.py` 生成明确标注的离线诊断图，材质和光照不等同于游戏画面。
