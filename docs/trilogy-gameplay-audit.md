## 跨章节必须补齐的内容

1. **统一生活与主线。** 已能以 Neo 接续相应章节并保留资金、证据与记录；Trinity 序幕另选。仍需把世界内访客、电话和邀约与生活日程真正融合。
2. **统一角色与结局。** 新旧两条路线的机器中枢对话者均已修正为机器集体；旧路线终战后继续谈判标记为游戏延伸。仍需合并重复路线。
3. **把选择变成后果。** 25 处哲学对话已逐场编写 75 个选项及回应，保存到本轮手记与循环记忆。现在主要影响哲学记录，尚不能当作普遍改变任务结果。
4. **保留真实世界状态。** 13 个节点的死亡/感染/恢复/失踪事件已由进度推导，读取旧存档也适用，切换角色不能复活本轮牺牲者；新循环才重置。飞船毁损、扩散与退兵的世界表现仍需制作。
5. **能力有成长和世界限制。** 普通 Thomas 的潜行、受训 Neo 的攻防、觉醒后的停弹和飞行、现实中的感知，需要清晰区分；Bane 船舱战不能套用矩阵超能力。
6. **默认保持 Neo 视角。** Trinity 序幕、Tank 阻止 Cypher、Niobe 航行、Kid 开门等保留为可选章节或短过场。用户主动选择其他角色时再接管，避免主线强制切人打断养成。
7. **场景按实际用途制作。** 公司隔间要服务潜行、楼外窄台要服务移动、高速路要能驾驶、后门和 Mobil 要实现空间规则。现有 64 个场景定义不等于 64 张完成地图。
8. **逐段验收画面与动作。** 建筑尺度、人物和服装、道具、动作、灯光、声音、镜头均需对应参考。矩阵有办公室日景、住宅、夜店和街道；现实有飞船/锡安，构造体有独立视觉语言。不能全部套绿色雨夜，也不能把简单几何数量当还原度。

## 游戏原创扩展与原片剧情的边界

日常工作/社交养成、随机异常、公司成功逃脱、蓝色药丸后继续游玩、建筑师另一扇门的可玩后果、多角色自由接管、通关后携带记录的新循环，均属于游戏扩展。

三部曲可以给循环设定提供主题依据，但原片尾声没有直接展示 Neo 回到办公室开始新一轮日常。游戏应在停战日出之后清楚结束电影路线，再进入原创循环。现有循环记录也不等于 NPC 已会根据上一轮记忆改变行为。

## 推荐制作顺序与完成标准

1. **P0 联系—逃亡—赴约—药丸：**先完成上面的两条分支，接住现有日常系统。两次真实游玩验证红蓝结果、追捕、检查点和读档。
2. **P1 第一部闭环：**觉醒/训练 → 先知 → 背叛 → 营救 → 地铁/觉醒结尾。利用现有大堂样板，补上其前后的装备、屋顶与救援，而不是把完成大堂算作完成第一部。
3. **P2 第二部闭环：**锡安生活/哲学 → 先知/Smith 围攻 → 钥匙匠/城堡/高速 → 多队断电 → 建筑师 → Trinity/现实能力。载具是这一批的主要机制依赖。
4. **P3 第三部闭环：**Mobil 营救 → Bane/金色感知 → 锡安防守与机器城两线 → 谈判/终战/停战。APU、飞行及大群机器需要分别做小场景验证。
5. **P4 原创循环扩展：**再让上一轮记忆、关系与选择影响下一轮异常和人物行动，形成用户要的开放世界长期玩法。

每段完成要同时满足：玩家知道目的 → 能实施有意义的操作 → 世界给出可理解的反应 → 失败/成功都有正确的状态衔接 → 保存后能继续 → 实机检查画面、动作和声音。只通过任务状态机测试不足以宣布该段完成。
