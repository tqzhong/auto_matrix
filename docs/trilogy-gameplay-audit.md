# 三部曲关键剧情：现状、缺口与制作清单

更新：2026-09-24。范围：完整关键剧情链及其可玩内容。制作目标与验收标准见 [正式方案](trilogy-production-plan.md)；下表随代码实施更新，保留未完成项。

本清单以当前工作区代码为依据，不是逐场实机画面验收，也不是电影逐镜头目录。合并短小过场，保留决定人物动机、因果关系、能力成长和结局的关键事件。表内“要补”均为待制作设计，不能当作现有功能。

## 审计结论

- 新电影路线现有 **105 个剧情节点**：第一部 43、第二部 33、第三部 29；涉及 **62 个场景定义**、39 类建筑布局。284 个步骤分为 70 个到达目标、161 个交互目标、21 个战斗目标、30 个反思选择、2 个驾驶护送目标。计数来自当前代码；交互目标中已有专用动作，也仍有仅靠计时和文字承接的原型。
- 第一部大堂营救有专用枪战机制；办公室已有巡逻/遮挡/暴露与两种逃亡结果。跳跃训练使用真实缺口与坠落；Mobil 在 Trainman 拒载并带车离开后才开放双向空间循环；Morpheus/Seraph 由本人参与非致命对练。高速公路已接入摩托车驾驶/动态车流/护送损伤；其余大量营救、变身、飞船等事件仍由文字代替对应操作。
- 旧的 **29 章 Neo 生活/剧情线**仍然保留。它与 105 节点路线不是两个可以相加的完成量，也还没有统一成同一条连续的生活主线。
- 日常时间、工作、吃饭、睡眠、社交、属性与金钱、有限的随机异常池、红蓝药丸结果、检查点和通关后的循环记录已有基础。异常并非由任意世界物件涌现，哲学选择也尚未普遍改变任务结果。
- 所以主要问题是：**故事名目大多有了，但人物实际做什么、如何失败、失败后怎样继续，以及场景如何连接，仍有大量缺口。**
- 性能最新进展：关闭录像的夜店同镜头基线约 11–12 fps，去除隐藏场景遍历与重复矩阵/阴影计算后为 19.4 fps；运行中的夜店 18.7 fps、办公室 20.3 fps。保留原有画质设置，仍未达到稳定流畅标准。报告与画面对照见 [性能验收](../output/gameplay/trilogy-performance-2026-09-22/README.md)；这不改变下表各组未完成的结论。

状态用语：**机制已有**指确实有对应状态与操作；**专用样板**指已实现该段特有机制但仍需打磨；**原型**指有地点、任务与文本，可能含通用战斗，缺少该段独有玩法。三者都不等于电影级画面完成。

## P0：用户指定的“墨菲斯联系 Neo → 躲避特工 → 赴约 → 红蓝药丸”

原片中，Neo 在公司窗外退缩，首次逃离失败并被捕，之后才再次接头。游戏保留这条原片路线，同时加入“成功逃脱”的可玩分支，满足玩家亲自脱身的要求；两条分支汇合到 Morpheus 的房间。[第一部成片转录](https://www.matrixfans.net/movies/the-matrix/transcript/)

2026-09-23 两条同一存档、使用控制器移动与明确交互的连续回归已从 Neo 的生活状态开始：保留的三项日常异常证据触发匿名信号后，玩家实际完成公寓电脑、来客、空心书、交易与白兔线索，进入夜店接近 Trinity、回应/提问并亲自离场，再继续公司追捕。两条路线分别覆盖成功逃脱后红色药丸，以及被捕、审讯、取出追踪器后蓝色药丸；都经过夜店后重载、约 57 秒乘车及中途重载、十三层实体路线、敲门和迎接。它证明从生活联系条件到药丸选择的状态与路线能连续衔接；日常随机异常的产生由独立测试覆盖，仍未替代浏览器人工连续长玩，也不代表人物与场景达到电影级。

2026-09-24 隔离浏览器从公司包裹、滑盖接听实际进入特工搜寻，停留工位触发被捕，再进入审讯室；刷新后恢复到审讯检查点。[159 秒实机录像](../output/gameplay/neo-longplay-2026-09-20/neo-2026-09-24T02-52-32-342Z.webm)记录这段失败分支。验收中发现未觉醒 Neo 的日常样式误将剧情目标箭头隐藏：审讯目标相距 9 米，却只提示“靠近后按 G”；已让剧情中的箭头和距离显示，独立浏览器复验通过。录像没有覆盖审讯后的接头与药丸，也没有完成成功逃亡分支，P0 连续人工验收仍未通过。

## 跨章节必须补齐的内容

1. **统一生活与主线。** 已能以 Neo 接续相应章节并保留资金、证据与记录；Trinity 序幕另选。仍需把世界内访客、电话和邀约与生活日程真正融合。
2. **统一角色与结局。** 新旧两条路线的机器中枢对话者均已修正为机器集体；旧路线终战后继续谈判标记为游戏延伸。仍需合并重复路线。
3. **把选择变成后果。** 25 处哲学对话已逐场编写 75 个选项及回应，保存到本轮手记与循环记忆。现在主要影响哲学记录，尚不能当作普遍改变任务结果。
4. **保留真实世界状态。** 13 个节点的死亡/感染/恢复/失踪事件已由进度推导，读取旧存档也适用，切换角色不能复活本轮牺牲者；新循环才重置。飞船毁损、扩散与退兵的世界表现仍需制作。
5. **能力有成长和世界限制。** 普通 Thomas 的潜行、受训 Neo 的攻防、觉醒后的停弹和飞行、现实中的感知，需要清晰区分；Bane 船舱战不能套用矩阵超能力。
6. **默认保持 Neo 视角。** Trinity 序幕、Tank 阻止 Cypher、Niobe 航行、Kid 开门等保留为可选章节或短过场。用户主动选择其他角色时再接管，避免主线强制切人打断养成。
7. **场景按实际用途制作。** 公司隔间要服务潜行、楼外窄台要服务移动、高速路要能驾驶、后门和 Mobil 要实现空间规则。现有 62 个场景定义不等于 62 张完成地图。
8. **逐段验收画面与动作。** 建筑尺度、人物和服装、道具、动作、灯光、声音、镜头均需对应参考。矩阵有办公室日景、住宅、夜店和街道；现实有飞船/锡安，构造体有独立视觉语言。不能全部套绿色雨夜，也不能把简单几何数量当还原度。

## 游戏原创扩展与原片剧情的边界

日常工作/社交养成、随机异常、公司成功逃脱、蓝色药丸后继续游玩、建筑师另一扇门的可玩后果、多角色自由接管、通关后携带记录的新循环，均属于游戏扩展。

三部曲可以给循环设定提供主题依据，但原片尾声没有直接展示 Neo 回到办公室开始新一轮日常。游戏应在停战日出之后清楚结束电影路线，再进入原创循环。现有循环记录也不等于 NPC 已会根据上一轮记忆改变行为。

## 推荐制作顺序与完成标准

1. **P0 联系—逃亡—赴约—药丸：**先完成上面的两条分支，接住现有日常系统。两次真实游玩验证红蓝结果、追捕、检查点和读档。
2. **P1 第一部闭环：**觉醒/训练 → 先知 → 背叛 → 营救 → 地铁/觉醒结尾。利用现有大堂样板，补上其前后的装备、屋顶与救援，而不是把完成大堂算作完成第一部。
3. **P2 第二部闭环：**锡安生活/哲学 → 先知/Smith 围攻 → 钥匙匠/城堡/高速 → 多队断电 → 建筑师 → Trinity/现实能力。载具是这一批的主要机制依赖。
4. **P3 第三部闭环：**Mobil 营救 → Bane/金色感知 → 锡安防守与机器城两线 → 谈判/终战/停战。APU、飞行及大群机器需要分别做小场景验证。
5. **P4 原创循环扩展：**再让上一轮记忆、关系与选择影响下一轮异常和人物行动，形成用户要的开放世界长期玩法。

每段完成要同时满足：玩家知道目的 → 能实施有意义的操作 → 世界给出可理解的反应 → 失败/成功都有正确的状态衔接 → 保存后能继续 → 实机检查画面、动作和声音。只通过任务状态机测试不足以宣布该段完成。
