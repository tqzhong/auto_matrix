## 用户反馈后修正制作方法

用户反馈：“我觉得都挺差的，我理解应该是针对证件照捏好人，然后后面就一直是这个3D，多调研一下3D建模，一些游戏的3D怎么建模的吧”。这不是等待用户评分，而是当前演员辨识度不合格。停止以耳廓、毛孔、发丝等局部修补推进相似度结论。

代码核对发现：运行时已经为每个角色缓存并复用同一个 GLB；问题在于其身份头模没有先通过审查。基础来自通用 MakeHuman 形态，原始正面／转面参考为生成图，后续主要是生成肖像的二维标志点插值和小幅侧向修正。最新四人都已烘焙皮肤，不能将问题误报为逐镜头换脸或实时照片贴片。被否决旧版的脸部表情目标也很有限：Neo 只有 jawOpen，Smith 只有 smithBrowRaise，Trinity/Morpheus 没有完整面部表情组。[模型审计](../output/characters/core-cast-six-hour-2026-10-25/rejected-head-pipeline-audit.json)

新方法按以下顺序执行：

1. 收集同一电影时期的真实正面、左右四分之三、侧面及头顶轮廓参考。标记照片中的俯仰、张嘴、皱眉、遮挡和透视；生成肖像不再作为身份几何的目标。单张证件照无法唯一确定三维深度。
2. 先做一个共享的中性头模。各照片拥有独立相机和表情，头骨／五官身份参数在各视角之间共用。粗拟合后在所有视角轮流调整，不分别捏出几张互不一致的脸。
3. 先检查无纹理灰模的头颅、颧骨、鼻唇、下颌、眼眶和耳位，保留未参与拟合的电影图作对照。灰模辨识度不合格时，不进入皮肤细节和毛发精修。
4. 形体确定后再制作皮肤底色、粗糙度、法线、眼球／泪线和发型；避免把电影光影、表情褶皱烘进永久中性几何。维护可编辑主 .blend 和明确导出版本。
5. 将头模接到现有身体、颈部、骨骼和衣领，制作表情形变及所需 LOD；同一个身份主模型用于各剧情。检查眨眼、张嘴、转头及触脸时的眼皮／牙齿／颈缝／手部交叉，再做实机读档。
