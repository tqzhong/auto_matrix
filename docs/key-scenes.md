# 关键电影片段：制作与验收

更新：2026-09-25。根据最新范围，选取三部曲的关键段落作为游戏主线骨架，不再以穷举影片全部地点作为完成标准。日常生活、随机异常、哲学选择与循环世界继续是骨架之外的游戏内容。

用户指定的首要段落是“墨菲斯联系 Neo → 办公室逃亡 → 接头赴约 → 红蓝药丸”。完整剧情与玩法缺口见 [三部曲关键剧情审计](trilogy-gameplay-audit.md)，包含当前 106 个节点的分组映射与成功逃脱/被捕两条路线的验收要求。

## 大堂本次实际实现

- Neo 与 Trinity 从安检外同步走入，行李触发报警灯和警报声后两人拔枪；入口警卫按保存时钟倒地并在战斗期间留在现场，离开场景时清理动作。
- 独立的窄长石材大厅、十根柱子、安检门、行李扫描机、值班台、报警控制台、武器箱、格栅、发光吊顶与三组电梯；离开场景释放资源。
- 三波共八名持枪警卫；警卫先显示固定瞄准方向再开火，移动和闪避可以躲开。Trinity 自动跟随侧翼、射击可见敌人，被玩家控制时停止自动协助。
- 构造体选择的双持紧凑型冲锋枪、泵动式霰弹枪或突击步枪分别保留弹匣、伤害、瞄准阈值与换弹时间；服务器使用鼠标俯仰角计算三维弹道。左键或 T 射击、R 换弹、F 近战、X 闪避、Q 子弹时间。
- 移动和射线使用同一组柱体数据。石材饰面受损、碎屑与尘雾可见，结构柱仍能挡弹；这不是完整的物理破碎模拟。
- 枪械附着手部骨骼，枪口闪光从可见武器发出；有射击回弹、弹道、命中反馈、室内枪声与短回声，沿用电影原声音乐系统。
- 安检段使用专用跟拍镜头；V 可切入 Neo 的实际眼位。演出期间锁定不合时宜的移动/攻击，战斗期间隐藏普通交谈提示。
- 清空三波后前往电梯，完成接通操作才打开电梯门并保存本段完成。死亡重试恢复本目标与弹匣，清除上一轮敌人和过期提示。

## 验收证据与限制

自动化测试：安检阶段/演员占用/暂停与保存恢复、入口警卫持续倒地、三种构造体装备、服务器上下瞄准、柱体遮挡、弹药耗尽与持久化换弹、固定瞄准后换位避弹、三波枪战到电梯、Trinity 协助及玩家接管、死亡重试、持枪侧移与第一/第三人称、报警台/武器箱/命中碎屑。完整回归 **341 / 341 通过**。

人工浏览器复核：在独立 3002 / 5174 临时存档中查看战斗第三人称和 V 主视角；实机发现入口警卫一秒后恢复站立且最终只弯腰的问题，先以回归测试复现，再修正为落地姿势和整场持续状态。暂停并刷新后仍恢复在第 2 波、Neo 生命 19、入口警卫保持倒地，普通交谈提示不再遮挡战斗；页面控制台无 warning / error。此次没有人工完成三波通关；三波到电梯由服务器集成测试验证，原玩家存档未被修改。

待提升：人物与衣服仍沿用现有资产；未实现电影中的侧手翻开枪等连续特技、逐块石材断裂、弹匣手部动画、敌人战术包抄、摄影级反射与完整空间音频。部分装饰与安检道具尚无精确碰撞，空间比例、材质、灯光、演员动作和逐镜头构图仍需成片对照。实机画面是可玩样板，不能称为完美还原。

每个后续关键片段都按同一顺序推进：参考画面与事件 → 空间/路线/碰撞 → 独有操作 → 人物配合和声音 → 实机对照、通关与重试。定时互动中的文字不能替代相应的可控动作。
