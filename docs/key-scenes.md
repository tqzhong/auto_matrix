# 关键电影片段：制作与验收

更新：2026-09-22。根据最新范围，选取三部曲的关键段落作为游戏主线骨架，不再以穷举影片全部地点作为完成标准。日常生活、随机异常、哲学选择与循环世界继续是骨架之外的游戏内容。

用户指定的首要段落是“墨菲斯联系 Neo → 办公室逃亡 → 接头赴约 → 红蓝药丸”。完整剧情与玩法缺口见 [三部曲关键剧情审计](trilogy-gameplay-audit.md)，包含当前 102 个节点的分组映射与成功逃脱/被捕两条路线的验收要求。

102 段现有索引保留作素材与剧情资料库。数量不是验收成绩。上述批次是制作顺序，不表示所有段落已经达到大堂样板的交互程度，更不表示电影级还原已经完成。

## 大堂本次实际实现

- 独立的窄长石材大厅、十根柱子、安检门、行李扫描机、值班台、格栅、发光吊顶与三组电梯；离开场景释放资源。
- 三波共八名持枪警卫；警卫先显示固定瞄准方向再开火，移动和闪避可以躲开。Trinity 自动跟随侧翼、射击可见敌人，被玩家控制时停止自动协助。
- 16 发弹匣、服务器控制伤害与射速、两秒换弹。左键或 T 射击、R 换弹、F 近战、X 闪避、Q 子弹时间。
- 移动和射线使用同一组柱体数据。石材饰面受损、碎屑与尘雾可见，结构柱仍能挡弹；这不是完整的物理破碎模拟。
- 枪械附着手部骨骼，枪口闪光从可见武器发出；有射击回弹、弹道、命中反馈、室内枪声与短回声，沿用电影原声音乐系统。
- 清空三波后前往电梯，完成接通操作才打开电梯门并保存本段完成。死亡重试恢复本目标与弹匣，清除上一轮敌人和过期提示。

## 验收证据与限制

自动化测试：柱体遮挡、弹药耗尽与持久化换弹、固定瞄准后换位避弹、三波枪战到电梯、Trinity 协助及玩家接管、死亡重试、持枪侧移与第一/第三人称、射击回弹及暂停。

人工浏览器试玩：进入大堂、行走、开启警戒、射击、子弹时间、闪避、使用医疗包、前两波增援、死亡及检查点恢复。人工试跑没有完成三波通关；三波到电梯的完成性由服务器集成测试验证。独立验收存档与原玩家存档分离。

待提升：人物与衣服仍沿用现有资产；未实现电影中的侧手翻开枪、逐块石材断裂、弹匣手部动画、敌人战术包抄、摄影级反射与完整空间音频。装饰桌椅和安检道具尚无精确碰撞。当前枪械采用水平朝向辅助瞄准，尚无上下自由瞄准。实机画面仍是游戏原型，不能称为完美还原。

每个后续关键片段都按同一顺序推进：参考画面与事件 → 空间/路线/碰撞 → 独有操作 → 人物配合和声音 → 实机对照、通关与重试。定时互动中的文字不能替代相应的可控动作。
